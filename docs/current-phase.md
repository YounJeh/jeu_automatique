Exit criteria: `entityDefinitionSchema` accepte `movementPattern: "fall" | "seek"` (optionnel, `"fall"` par défaut, aucune régression sur dodge/collect/shooter) ; `GenericRuntime` déplace une entité `"seek"` vers la position courante du joueur à chaque frame ; `gameDefinitionPlayabilityRules` exclut les entités `"seek"` des formules spécifiques à la chute et applique une règle dédiée déterministe (vitesse poursuivant vs joueur) ; un preset `survival` (`GameDefinition`-only, sans moteur legacy) passe schéma/sémantique/jouabilité et est exécutable par `GenericRuntime` ; le jeu built-in correspondant n'apparaît dans le catalogue que si `GENERIC_RUNTIME_ENABLED=true`, sans régression du catalogue quand le flag est désactivé ; `docs/mechanics/avoid.md` documente les deux `movementPattern` ; un cas est ajouté à `tests/evals/game-generation-cases.json` ; pnpm check et pnpm test:e2e passent flag `GENERIC_RUNTIME_ENABLED` activé et désactivé.
